# Heartshop Vouchers v0.1.0 — release notes

Released on 2026-11-13.

Heartshop Vouchers is a small MIT-licensed, self-hosted shop from Heartmade Studio.
It sells and redeems service vouchers using PAYMOVE.io payments. Invoice issuance
and booking remain outside the application; the seller can configure manual
invoice-request instructions in the page, terms and buyer email.

This first version includes a local simulation, server-side prices,
signed payment events, a seller panel, durable mail queue and merchant setup docs.
Indexing is opt-in, with generated public metadata and permanent noindex on
transaction/private pages. Read the hosting proposal before choosing a runtime.

Before upgrading a configured installation: back up and test restore, reapply
merchant configuration privately, rebuild the storefront, inspect the diff and
publish a mutually compatible config/PHP/HTML release atomically. Keep all
historical order data. Review [edition isolation](https://github.com/heartmade-studio/Heartshop-Vouchers/blob/v0.1.0/docs/edition-isolation.md) for remaining coupling.

PHP 8.2 is the tested minimum; prefer 8.5 for new installations.
The offline regression suite covers PHP 8.2–8.5. Each merchant must validate
their hosting configuration, payment provider and fulfillment before going live.
No cart, inventory, variants, automatic refunds or autonomous payment agent.

Need implementation help? [Heartmade websites and shops](https://heartmade.pl/websites).
