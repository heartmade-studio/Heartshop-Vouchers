# Heartshop Vouchers v0.2.0

Released on 2026-11-16.

The sample storefront now offers three massage vouchers. Buyers can choose a one-hour massage for PLN 250, a two-hour massage or Chinese cupping massage for PLN 400, or a two-hour massage with a chocolate ceremony for PLN 600. Each price-table link opens checkout with that option selected.

Each printed or downloaded voucher shows its unit value recorded at purchase. An order for two PLN 400 vouchers totals PLN 800 and prints PLN 400 on each voucher.

## Checkout and availability

- The storefront price table, starting price and checkout selector follow the offers available for new purchases. When sales are paused, the storefront displays a notice and checkout disables new purchases.
- A buyer can resume a payment for an offer that is still configured but has been withdrawn from new sales. Checkout preserves the selected voucher and payment attempt.
- Indexed storefronts with multiple options publish the price range and offer count. The storefront build reports an error if a template is missing the insertion point for the price table.

## Upgrading from v0.1.0

Back up the database and merchant configuration. Keep historical offer IDs and order data, merge the catalogue changes into your configuration, and rebuild with `php scripts/heartshop/build-storefront.php`. Review the generated price table and publish the matching PHP, HTML and assets together. Test voucher selection, payment resumption and PDF download on staging before enabling sales.
